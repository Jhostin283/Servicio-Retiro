# Interface Design Guidelines (skills.sh - mattpocock/skills)

## Business-First Interface Design
- **Eliminate Technical Noise**: The user interface must represent the business domain without displaying internal infrastructure terms (Docker, RabbitMQ, Swagger, Postgres).
- **Clear Information Hierarchy**: Group related actions in elevated cards with clear header titles, badge indicators, and primary action buttons.
- **Responsive Layout**: Mobile-first single-column structure that expands into a multi-column desktop grid.
